# 城市渲染问题清单（按优先级）

每一条都标注了**是否已确认**。区分「已确认」和「推测」很重要：本项目已经因为把推测当结论而浪费过时间
（把黑色天空归因于几何、以为箭头来自新场景，而实际画面里跑的还是旧渲染器）。

## P0 — 阻断性：不解决就看不到任何新成果

| # | 问题 | 状态 |
| --- | --- | --- |
| P0.1 | **新的 Rust 城市场景从未被渲染过。** 用户看到的所有画面都来自旧的 `Terrain3D.tsx`，它读 `modernCities` 而不读 `cityScenes`。所以「建筑是纵向条纹」「箭头是白块」都是旧渲染器的缺陷，不是新代码的缺陷。 | 已确认 |
| P0.2 | 旧渲染器的 `metreUVGenerator`（`Terrain3D.tsx:824-855`）把 shape 空间的 `y` 当高度读，非轴对齐墙面导致 `U` 退化为常数 → 竖条纹。烘焙好的立面贴图解码后从未赋给材质 → 纯白。 | 已确认 |
| P0.3 | 载荷 428 MB，浏览器无法加载。已加 `--scene-only` 与 `tiny_city`（840 m 城市，19 MB）作为快速回路。 | 已解决 |

**当前状态**：新的城市查看器已写好（`src/city/cityScene.ts`、`sky.ts`、`CityViewer.tsx`），
但**还没有成功截过一张图**。这是 P0.1 的最后一步，也是其他一切的前提。

## P1 — 你已指出的可见缺陷

| # | 问题 | 根因 | 状态 |
| --- | --- | --- | --- |
| P1.1 | **地面杂乱白线** | `furniture.rs` 架空电线：①电线把当前杆与上一杆直连，而杆每 34 m 换边；②`previous_pole` 只存 `(road, station)`，上一杆位置用**当前** `side` 重新求值 → 电线斜穿马路；③`rng.unit()*TAU` 让横担随机朝向。**另外还有一个漏掉的缺陷**：导线偏移硬编码 ±0.72/±0.48 m，而横担端点在 ±1.71/±1.35 m，电线悬空约 1 m 什么都没挂。 | **已修** |
| P1.2 | **天是黑的** | 场景没有环境。新建 sky shader 穹顶 + 烘焙 PMREM 环境贴图。 | 已修（待验证） |
| P1.3 | **白色浓雾** | 雾的范围没有按场景尺度推导。改为线性雾，near/far 由城市尺寸决定。 | 已修（待验证） |
| P1.4 | **建筑是纵向条纹、没有窗户** | UV 以场景单位发出，而贴图 `repeat` 应为 `1/物理尺寸`。新渲染器 UV 用米、`repeat` 取倒数。 | 已修（待验证） |
| P1.5 | **箭头是白块** | 旧渲染器的箭头。Rust 侧 `spec.rs` 的 GB 轮廓数据本身与参考项目一致，怀疑是 `drive_arrow` 的绕序/侧向轴。 | 交给街道 agent 核查 |
| P1.6 | 整体发白、不真实 | 调色板用了高饱和「颜色」而非**反射率**。真实叶片反射率 5–20%、沥青 4–12%、玻璃 0.06–0.12。`species.rs` 已改为物理反射率并加测试锁死。 | 已修 |

## P3 — 已知差距（如实记录）

- 无景深 / TAA
- 无按距离的 LOD 分级
- 无行人与非机动车
- 立面无法线贴图
- 建筑基座不做地形开挖

## 验收判据

- 街道视角能读出：楼层层数、店铺招牌、停止线、横道、行道树、车辆。
- 天际线能数出至少 6 种不同立面配色。
- 俯视能看出路口的箱体 + 转角铺装 + 横道。
- 车辆沿车道行驶并穿过路口连接曲线，不瞬移。
- **电线不得跨越车行道**（`no_wire_crosses_a_carriageway` 已断言）。
